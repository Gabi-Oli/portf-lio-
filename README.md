Este site foi criado com uma proposta visual **elegante, minimalista e responsiva**, buscando transmitir profissionalismo sem perder a identidade pessoal.

- projetos selecionados;
- diferenciais profissionais;
- links de contato;

- layout adaptado para celular, tablet e desktop.

## 🎨 Destaques de design

O projeto utiliza:

- paleta neutra com tons sofisticados;
- tipografia **Playfair Display** para títulos;
- tipografia **Lato** para textos;
- cartões com bordas suaves;
- sombras discretas;
- microinterações nos botões e cards;
- hierarquia visual clara;
- espaçamento generoso para facilitar a leitura.

## 📱 Responsividade

O layout possui breakpoints para diferentes tamanhos de tela, reorganizando:

- navegação;
- seção principal;
- habilidades;
- projetos;
- bloco de diferenciais;
- contatos e rodapé.

A experiência é pensada primeiro para leitura confortável e navegação simples em dispositivos móveis, sem deixar de aproveitar telas maiores.
